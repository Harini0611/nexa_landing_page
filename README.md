# nexa_landing_page
This is a responsive product landing page created as part of my internship task. The page focuses on a clean layout, simple navigation, and a clear presentation of the product.

## Features

- Fixed navigation bar
- Home/Hero section
- Call-to-action button
- Features section
- About section
- Responsive layout
- Footer with contact and social links
- Consistent colors and typography
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- Google Fonts
